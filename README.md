# Vidpick

Vidpick 是一个本地桌面抖音文案采集工具。

## 用途

采集抖音作品详情/介绍页的正文，并按博主整理保存，便于后续使用。

## 核心需求

- 支持输入单个链接或批量链接。
- 链接必须先识别；只有识别成功后才能开始任务。
- 第一阶段提取抖音作品详情/介绍页的完整正文。
- 提供统一的任务进度区和状态/日志区，显示当前步骤、成功或失败、开始时间、结束时间和耗时。
- 按博主名称建立输出目录；每篇保存为 TXT，每个博主维护一个 JSONL 文件。
- 任务完成后支持打开保存文件夹。

## 使用方式

输入一个或多个抖音链接，先执行链接识别；识别成功后开始采集任务，在界面查看进度和日志。采集结果保存到按博主名称建立的目录中，完成后可直接打开保存文件夹。

## 当前阶段目标

完成第一阶段：稳定提取抖音作品详情/介绍页的完整正文，并按既定格式保存。

## 关键约束

- UI 保持简洁现代，偏 iOS 设计语言。
- 优先快速落地和稳定使用，避免过度设计。
- 第一阶段不做视频下载、图片下载、主页全量采集、AI 分析或其他扩展功能。
