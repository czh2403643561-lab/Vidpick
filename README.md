# Vidpick

Vidpick 是一个本地桌面抖音作品采集工具。

## 快速开始

第一次：双击 `start_vidpick.bat`，首次初始化需要等待一会儿。以后双击 `Vidpick.vbs`，直接打开软件且不会显示黑色命令窗口。

单个模式：粘贴作品链接 → 识别 → 开始任务。批量模式：粘贴博主主页 → 识别 → 勾选作品 → 确认 → 开始任务。

输出文件在 `output/<博主名>/`。

## 用途

采集抖音作品详情/介绍页的正文、无水印图文图片/封面和视频作品原视频，并按博主整理保存，便于后续使用。

## 核心需求

- 支持单个作品链接，或一个博主主页链接批量选择作品。
- 链接必须先识别；只有识别成功后才能开始任务。
- 提取抖音作品详情/介绍页的完整正文；图文作品同步采集无水印图片，视频作品可采集封面与原视频文件。
- 提供统一的任务进度区和状态/日志区，显示当前步骤、成功或失败、开始时间、结束时间和耗时。
- 按博主名称建立输出目录；每篇保存为 TXT，每个博主维护一个 JSONL 文件。
- 任务完成后支持打开保存文件夹。

## 使用方式

单个模式：粘贴一个作品分享链接，先识别作品信息，再开始保存。

批量模式：粘贴一个博主主页分享链接。识别完成后会显示当前环境可访问的公开作品，并弹出选择窗口；勾选作品后开始顺序采集。任务会复用同一个 Chromium 会话，单项失败不会中断后续作品。

两种模式都会在界面显示当前步骤、进度和日志。采集结果保存到按博主名称建立的目录中，完成后可直接打开保存文件夹。

点击顶部的设置图标可选择本次采集“文案”“图片/封面”和“视频”。文案保存为 `content.txt`；图片保存图文无水印图片与封面，视频作品的“视频”选项保存为 `video.mp4`。视频默认关闭，设置会在下次启动时保留；未选择的已有内容不会被删除。

顶部星形入口用于管理本地收藏的博主。批量识别成功后，可在“博主”一行点击空心星收藏；收藏数据保存在项目目录的 `favorites.json`。收藏窗口可查看博主最近一次识别的作品数量和时间；点击“查看”只会切换到博主批量模式并填入主页链接，不会自动识别或采集。

## 当前阶段目标

稳定提取抖音作品详情/介绍页的完整正文；图文作品保存正文与无水印图片，视频作品可独立保存正文、封面和原视频。

## 关键约束

- UI 保持简洁现代，偏 iOS 设计语言。
- 优先快速落地和稳定使用，避免过度设计。
- 不做 AI 分析或其他扩展功能；主页只读取当前环境可访问的公开作品，不绕过登录或平台限制。
